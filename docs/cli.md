# `moss` command reference

Generated by `moss generate-docs docs/cli.md`. Do not edit by hand.

```text
Deploy and update a consumer-owned NixOS machine. Never use install to repair a host

Usage: moss <COMMAND>

Commands:
  discover    Record the target's hardware and selected whole disk (no changes to target)
  preflight   Recheck a private discovery record against the live target
  install     Build a pushed commit and, after typed confirmation, erase the selected disk
  bootstrap   Seed the installed host with its exact installed commit and private machine facts
  update      Fetch a descendant commit, build and switch; never partitions a disk
  transition  Move an installed candidate to a reviewed branch with a reviewed machine file
  help        Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help

  -V, --version
          Print version

```

## `moss discover`

```text
Record the target's hardware and selected whole disk (no changes to target)

Usage: moss discover <TARGET> <DISK> <RECORD>

Arguments:
  <TARGET>
          Verified rescue-environment SSH target (e.g. root@HOST)

  <DISK>
          Whole-disk path, checked against lsblk (e.g. /dev/vda)

  <RECORD>
          New private JSON record path (created mode 0600)

Options:
  -h, --help
          Print help

```

## `moss install`

```text
Build a pushed commit and, after typed confirmation, erase the selected disk

Usage: moss install <RECORD> <REPO> <REV> <MACHINE> <HOST> <BRANCH> <RECEIPT>

Arguments:
  <RECORD>
          Discovery record, rechecked before build and before disk erase

  <REPO>
          Clean consumer Git checkout

  <REV>
          Full 40-character pushed commit ID

  <MACHINE>
          Private credential-free machine.nix directory

  <HOST>
          NixOS flake output name

  <BRANCH>
          Pushed branch whose head must equal REV

  <RECEIPT>
          New off-host install receipt path (created mode 0600)

Options:
  -h, --help
          Print help

```
