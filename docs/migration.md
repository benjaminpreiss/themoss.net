For each consumer: (1) review the pin PR and generated machine facts; (2) push the exact candidate revision to a branch, install only on a disposable VM using `install ... PUSHED_BRANCH PRIVATE_INSTALL_RECEIPT.json`; (3) verify the **new** SSH host key at the console, then `bootstrap` from the receipt with root-only paths and retry an interrupted upload; (4) assert the target revision equals the installed commit and the candidate timer is **absent before bootstrap**; (5) merge to `main`, prepare a reviewed credential-free `machine.nix` (for the relay, with `autoUpdate = true`), and test `transition` without Disko; (6) only then delete duplicated orchestration and enable the relay timer through its reviewed NixOS policy. If the merge rewrites history, transition must reject it; do not silently rebaseline. Neither consumer nor a deployed machine is modified by this repo's change.
